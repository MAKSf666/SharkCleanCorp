Shark Cleaning LLC — код сайту

1. Розпакуй ZIP.
2. Відкрий папку Shark-Cleaning-LLC у VS Code.
3. Відкрий index.html у браузері або через Live Server.

index.html — текст, секції та картки товарів.
style.css — кольори, шрифти, розташування та мобільна версія.
script.js — мобільне меню й рік у футері.
hero.png — головне зображення.
IMG_4721.jpeg — Glass Cleaner.
IMG_4722.jpeg — Bathroom Foam Spray.
IMG_4723.jpeg — All Purpose Cleaner.
IMG_4724.jpeg — Cleaning Paste.

Фото товарів — оригінальні скриншоти; CSS показує лише область із продуктом.
Шрифти завантажуються з Google Fonts, а без інтернету використовуються системні.
Контакти, ціни, об’єми, оформлення замовлень і оплата ще не додані.
Сайт статичний: встановлювати Node.js або залежності не потрібно.
